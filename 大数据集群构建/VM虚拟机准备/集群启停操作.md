# 集群启停操作

> 目前，启停集群需要操作这些组件：
> 1、hadoop集群
> 2、dinky
> 3、docker（里面有一些轻量级的单点组件，例如mysql）


### hadoop集群启停

因为已经写好脚本，所以直接在hadoop101节点上，这样操作：

```sh
# 切换到hadoop的jdk配置，临时激活相关环境变量
source ~/go-hadoop.sh
# 启动集群
./cluster.sh  start
# 停止集群
./cluster.sh  stop
# 通过jps查看集群状态（hadoop相关进程是否正常跑起来了）
./cluster.sh  status
```

### dinky启停

通过dinky官方自己提供的脚本启停

```sh
# 切换到dinky目录
cd /home/leoyi/module/dinky
# 启动单点dinky实例
./bin/auto.sh  start
# 停止实例
./bin/auto.sh stop
# 查看运行状态
./bin/auto.sh  status
```

### docker启停

其实就是注意一下里面一些容器是否正常运行，例如mysql容器，因为dinky持久化用户信息用到了mysql，dataease也是这样，如果mysql容器没有跑起来，其他大数据组件也会运行失败
